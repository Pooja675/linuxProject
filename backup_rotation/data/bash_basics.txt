BASH SCRIPTING BASICS
=====================

1. Always start a script with a shebang: #!/bin/bash
2. Make it executable: chmod +x script.sh
3. Variables: name="Pooja"   (no spaces around =)
4. Use a variable: echo "$name"
5. Arguments: $1, $2, $3 ... ; $# is the argument count
6. Conditions need spaces: [[ $a -eq $b ]]
7. Arithmetic: $((a + b)) or (( a < b ))
8. Loops: for, while, until
9. Check the last command's status with $?
10. Quote your variables to avoid word-splitting bugs.
